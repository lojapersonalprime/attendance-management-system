# Suporte

Use as issues do GitHub para dúvidas reproduzíveis, sugestões pequenas e problemas que não envolvam segurança ou dados reais. Antes de abrir uma issue, consulte o README e a documentação em `docs/`.

Não publique arquivos TXT reais, credenciais, URLs de banco, dados de funcionários ou relatórios. Para vulnerabilidades, siga [SECURITY.md](SECURITY.md).

Para solicitar uma funcionalidade, explique o caso de uso, o resultado esperado e como ele se encaixa no escopo do MVP.
